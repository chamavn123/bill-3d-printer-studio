# Bill 3D Printer Studio

A browser-based start and end G-code builder for Bambu Lab A1, A1 mini, and P1S printers with 0.4 mm nozzles.

Includes configurable routines, an animated 2D routine preview, and G-code copy/download. The walkthrough is illustrative, not an exact movement or collision simulation.

Serve these files over HTTP, or enable GitHub Pages from the main branch and root folder. No ChatGPT subscription or API key is required to run the site.

Generated templates must be processed in Bambu Studio before use. Review the output and supervise physical testing. Original Bambu Studio template attribution and license are included in NOTICE.txt and BambuStudio-LICENSE.txt.
